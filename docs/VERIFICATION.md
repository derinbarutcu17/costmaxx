## 2. Findings

### Bugs found and fixed during this audit

1. **ReadRange panics on inverted range** (internal/artifacts/store.go).
   `ReadRange(3, 1)` panicked: slice bounds out of range. Fixed with a clamp.
   No production caller today, but it is exported API used by evidence tooling.
   Regression test: TestReadRangeEdges.

2. **Signal-killed commands report Exit: -1** (internal/mcp/server.go).
   `kill -TERM $$` produced Exit: -1, losing the cause. Fixed to report
   128+signal (143 for SIGTERM). Test: TestStdioRunSignalDeath.

3. **Concurrent processes fail to start on one data dir** (internal/store/sqlite.go).
   Two costmaxx processes on the same HOME hit `SQLITE_BUSY` during migrate.
   Real risk: Codex hook invocations and the MCP server share ~/.costmax.
   Fixed with a bounded retry in Open() plus closing the DB handle on failure
   (the old code leaked the handle). Test: TestStdioConcurrentProcessesSameDataDir.

### Security findings (documented, not fixed)

4. **Redactor misses common secret formats.** Not detected:
   `aws_secret_access_key=...`, `Authorization: Bearer ...`, spaced
   assignments (`api_key = "..."`). Regexes require the keyword directly
   before `=` or `:` and do not include AWS or Bearer forms. Detected: SSN,
   JWT, email, `api_key=`/`token=`/`password:` without spaces, URLs with
   embedded credentials. Test: TestRedactorMissesCommonFormats.

5. **Command strings are not redacted.** The command line is echoed in the
   model-visible response and persisted unredacted in artifact metadata
   (SQLite). The model already knows the command it sent, so exposure is low,
   but a command containing a secret (e.g. curl with an inline token) lands
   in ~/.costmax/costmax.db in the clear. Output content is redacted before
   storage. Test: TestStdioSecretRedactedInResponseAndArtifact documents the
   split.

### Classifier quality findings (documented, not fixed)

6. **Substring false positives.** Any command containing "test" or "build"
   classifies as test/build: `cd /tmp/test-data && ls` -> test,
   `cat ~/build-notes.md` -> build. Commands are keyword-matched, not
   tokenized. Tests: TestPathWithTestSubstringIsFalsePositive,
   TestPathWithBuildSubstringIsFalsePositive.

7. **False negatives.** Bare `jest`, `mocha`, `rspec` (matchers require a
   trailing space), and `find . -type f` without `-name` (&& precedence in
   the classifier) fall through to terminal. Tests:
   TestTestCommandSubstrings, TestFindWithoutNameIsNotSearch.

8. **JSON signature is fragile.** Leading whitespace before `{` defeats the
   JSON classifier (falls to terminal). Test:
   TestJSONSignatureNeedsLeadingBrace.

### Verified by-design behavior

- Policy: passthrough at <= 160 raw tokens or when compact + 80 >= raw;
  preserve_full for binary and reducer-less output; artifact_required for
  terminal/generic; post-render guard downgrades false savings.
- Reducer gates: terminal > 1000 bytes, generic > 2000 bytes. Small outputs
  get no reducer and pass through.
- All reducers are deterministic under adversarial input (empty, ANSI,
  unicode, malformed, threshold-sized); no panics, no errors.
- Reducers can produce compact output larger than tiny inputs; the guard
  backstops the claim.
- Token estimator is len/4: CJK undercounts (0.75 tokens per char), emoji
  overcounts (1 token per 4-byte emoji). Policy comparisons are
  self-consistent because both sides use the same estimator.
- GC drift is the only storage inconsistency found.

## 6. Verdict

CostMax's claims hold under this audit. The honesty posture is intact:
hooks are observe-only (verified at the real-binary level), the guard
prevents false savings claims, artifacts round-trip byte-identically, and
the fresh 20x3 live run passes the strict transcript audit with 60/60 active
quality and 60.6% model-visible token reduction, reproducing the retained
run's numbers on a fresh binary.

Three real bugs found and fixed during the audit (ReadRange panic, signal
exit code -1, concurrent-start SQLITE_BUSY). The main quality gaps are the
redactor (misses AWS/Bearer/spaced-assignment formats) and the classifier
(substring false positives, trailing-space false negatives). COSTMAX_DISABLE
help text is a dead claim. GC leaves DB rows behind. None of these block the
supported claim, but the redactor gaps matter most if CostMax is pointed at
repositories whose command output carries credentials.

The project is now fully proven within its stated boundaries: Codex-only,
opt-in MCP, deterministic fixtures, observe-only hooks, token estimates not
billed dollars.
